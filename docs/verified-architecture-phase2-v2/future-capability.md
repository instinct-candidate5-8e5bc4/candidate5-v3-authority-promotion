# Future capability analysis

The contract can represent standing, floor sitting, chair sitting plus feet on floor, floor/wall leaning, standing/wall leaning, elevated legs, bed/stretcher contact, kneeling, recovery position, vehicle seat/backrest/floor and multiple partial supports once each posture has an honestly authored rigid full-body collision representation and exact contact regions/surfaces/capabilities.

It does not implement those postures. Non-axis-aligned vehicle seats, articulated motion, deformable bodies, friction, load/stability, force equilibrium, entrapment and constraint persistence need future explicit extensions. Entrapment is not support and must not be disguised as a support contact. ClinicalPresentation and VisualRepresentation remain separate; symptoms and sex semantics cannot generate collision/contact geometry.
