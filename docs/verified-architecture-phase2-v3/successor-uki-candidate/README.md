# Minimal Cloud Boot Adapter and Successor UKI Implementation Candidate

Status: `UNSIGNED_IMPLEMENTATION_CANDIDATE_READY_FOR_INDEPENDENT_REVIEW`

This candidate is not authorized for execution, boot, signing, cloud use or provisioning. It contains no private key, PFX, public production certificate or signed successor UKI.

`cloud-boot-adapter.sh` is the new first init. It uses only the already pinned BusyBox closure, resolves six exact GCP device serials from sysfs, rejects unknown `v3-*` and non-unique identities, creates the two canonical dm-verity aliases, mounts four exact ext4 volumes with fixed modes, emits non-secret deterministic evidence, verifies the preserved old init digest and hands off to `/init.root-admitter`. The preserved old init then performs the unchanged dm-verity, mount, freshness and Root-Admitter checks.

`build-successor.py` deterministically copies the certified initramfs in a temporary directory, renames its byte-identical `/init`, installs the adapter as `/init`, emits newc CPIO bytes and constructs the unsigned PE/COFF UKI with the byte-identical stub, kernel and command line. It writes a canonical inventory. Running it twice must reproduce all generated bytes.

The exact device names are:

- `v3-rootfs-data`
- `v3-rootfs-hash`
- `v3-reviewed-root`
- `v3-reviewed-input`
- `v3-reviewed-output`
- `v3-reviewed-evidence`

The device manifest and adapter reject any other disk serial beginning `v3-`. Disks outside this reserved namespace are non-authoritative platform/boot devices and are ignored. The adapter does not read metadata, DNS or network state.

Review must inspect the adapter and generator, reproduce the CPIO and unsigned UKI, extract the CPIO to confirm the sole intentional additions/replacement, and run disposable VM-hosted hostile tests for missing, extra, duplicate, swapped and ambiguous device identities; wrong mount source/type/options; changed manifest or adapter; altered old init; and failed handoff. The production-signing, sole-`db` binding and firmware acceptance checks remain at the later signing boundary defined in `minimal-successor-uki-design.md`.
