# Executable hostile runtime evidence

Each of the twelve cases is a distinct generated initramfs mutation, or a distinct initramfs plus disk mutation, booted in a fresh real QEMU VM. The committed transcripts contain the case name, expected designed fail-closed terminal, initramfs SHA-256, guest serial output, observed E_* terminal, and QEMU wrapper exit. `hostile-runtime-results.v1.json` binds every transcript and initramfs identity. The initramfs bytes are reproducibly generated by `build-hostile-runtime-matrix.py`; large generated CPIOs and disposable ext4 disks are intentionally not committed.

`adapter-substitution` is an executable static-boundary test: an immutable init shim hashes the mutated adapter-under-test inside the VM and emits `E_ADAPTER_IDENTITY` before it can run. All other cases execute the candidate adapter mutation itself. No marker-presence or reachability-only result is classified as runtime evidence.
